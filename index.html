a browser for linux people

Hawk

Small. Written in C. No telemetry, no account, no "AI", no drama. Search runs on your machine or not at all.

curl -fsSL https://sf0e.github.io/hawk-site/get/install.sh | sh — or build it from source

what it is

Hawk is a GTK4 + WebKitGTK browser written in C. It has one pill-shaped bar up top, small pill tabs below it, and nothing else. It looks like a Safari that lost its funding round, which is the nicest thing I can say about it.

  • tabs: Ctrl+T open, Alt+W close, Ctrl+L bar, Ctrl+R reload
  • cookies persist — your logins survive — nothing is wiped on exit
  • third-party cookies blocked, camera & mic off, one fixed user agent
  • popups become tabs, because popups are for cowards
  • dark mode that also turns the web dark. yes, for real

what it is not

  • not a Chrome reskin
  • not a data collector
  • not available for Windows or macOS, and never will be
  • not finished

the search part

Hawk keeps a private SearXNG on 127.0.0.1:8080. It boots when you open the browser, dies when you close it, and your queries never leave the machine to go find a search engine. If the backend can't start, Hawk sighs and uses DuckDuckGo instead.

status

alpha. v0.1.0-alpha is out and the install command at the top of this page works. Linux only. It's a working browser — tabs, pills, dark mode, local search — with a few rough edges, listed honestly in the README, which I recommend reading out loud to the browser.
