about

Hawk, a browser that stays out of your way. Here is who made it, why, and what it will never pretend to be.

why it exists

Because the browsers that exist are always doing something. Updating in the background. Offering you an account. Synthesizing a summary of the article you were about to read. Hawk exists to do the one thing a browser is for — show you the web — and then get out of the way.

It's written in C because C doesn't need a runtime, a framework-of-the- month, or a podcast. It uses GTK4 and WebKitGTK because those are the closest thing Linux has to plumbing that's already installed.

privacy, in practice

  • your queries go to a SearXNG running on your own machine, or to a plain DuckDuckGo HTML page, never to a corporation's API
  • cookies are kept — you stay logged in — but third-party cookies are blocked by default
  • nothing phones home. there is no home to phone.
  • your data is one folder: ~/.hawk. delete it and the browser remembers nothing about you, which is the correct way to forget someone

can it run Firefox / Mozilla add-ons?

No. Honest answer, no plans to fake it.

Firefox add-ons from AMO are written against the WebExtensions API (browser.*), which is Mozilla's extension runtime. Hawk is built on WebKitGTK, and WebKitGTK does not implement that API, has no add-on store, and exposes a completely different (native-code) extension mechanism instead. There is no compatibility layer that makes browser.storage exist in WebKitGTK — one would have to reimplement the entire WebExtension API surface to host AMO add-ons, which is roughly the same work as writing a second browser engine.

So: no uBlock Origin, no Privacy Badger, none of it. What Hawk does instead — third-party cookie blocking, media off, local search — is built in, so the most common reasons people install those extensions are already handled without the middleman.

status & roadmap

alpha. v0.1.0-alpha. It's a working browser: tabs, URL memory with type-ahead, sessions, persistent cookies, dark mode, local search. What it is not is v1.0.

The bugs that used to live here — logging you out on every close, forgetting every URL, leaving a search engine running after you quit, YouTube barely working — are dead. Their gravestones are in the commit log, if you want to read them.
