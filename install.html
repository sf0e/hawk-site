install & uninstall

In one line. And out of your system, if it ever comes to that.

install

Linux only. GTK4 + WebKitGTK 6.0 are the only real requirements; the script installs them with your package manager.

curl -fsSL https://sf0e.github.io/hawk-site/get/install.sh | sh

First launch sets up the local search engine, which is slow and makes coffee. Every launch after that is fine. It doesn't need root, but it will happily accept your sudo password for the build dependencies.

uninstall

The script lives right next to the installer, because leaving a browser installed after someone asks you to leave is not good manners.

curl -fsSL https://sf0e.github.io/hawk-site/get/uninstall.sh | sh

That removes the binary, the search manager, the desktop entry and the icons, and leaves ~/.hawk (your cookies, history, sessions) in place — in case you come back.

curl -fsSL https://sf0e.github.io/hawk-site/get/uninstall.sh | sh -s -- --purge

--purge also deletes ~/.hawk. All of it. Your logins, your history, the search engine. Gone. This is the point of no return and the script will say so out loud before the end.

build it yourself

If you'd rather watch it burn in a terminal:

git clone https://github.com/sf0e/hawk && cd hawk
meson setup build
ninja -C build
./build/hawk

Dependencies: gtk4, webkitgtk-6.0 development headers, meson, ninja, a C compiler.

where things live

Hawk puts everything in one place, because "where did that go" is not a feature:

  • ~/.hawk/hawk.ini — settings (edit from hawk://config, the browser-level way)
  • ~/.hawk/history — the URLs it remembers and types ahead
  • ~/.hawk/session — your open tabs, saved on close
  • ~/.hawk/cookies/cookies.sqlite — cookies. they persist. you stay logged in.
  • ~/.hawk/searchd/ — the private SearXNG engine and its pidfile
